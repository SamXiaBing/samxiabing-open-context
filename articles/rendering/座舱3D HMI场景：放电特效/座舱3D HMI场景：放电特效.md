> 上一篇介绍了充电溶解特效：[座舱3D HMI场景：充电特效](https://mp.weixin.qq.com/s/11f-tEIeHAuRpgG9jKMdpg)。包括全局变量注入溶解原点、C# 侧 Keyword 切换、Shader 端环形扫描波 + 三角波脉冲 + pow(2) + 青绿配色。本文不再赘述这些共用部分，**只写放电与充电的差异**。

放电与充电其实是写在同一个 Shader工具插件（Shadergraph,ASE）的Function中，共用溶解的空间坐标原点，且最终和 Albedo 叠加。但是本文介绍的放电特效设计需求与充电不同，它不是从某个点向外扩散，而是在充电口盖的区域内做“呼吸灯”效果，以体现能量在供给的含义。开发的差异集中在三点：**强度计算**、**时间节奏**、**颜色**。

---

## 一、C# 侧

放电只需在充电的基础上多开一个 Keyword：`_ISDISCHARGE_ON`。它在 Function 内部实现连连看路径上往放电逻辑切换的目的，其余逻辑（总开关、溶解原点）与充电完全相同，不再赘述。

---

## 二、Shader 端

### 2.1 强度计算：距离梯度 → pow(10) 锐利聚焦

充电特效用 `frac + smoothstep` 构造环形扫描波。而放电不需要扫描动效，**直接使用像素到充电口的距离做衰减处理**：

```hlsl
float maxRadius = 6.0;        // 有效影响半径
float normalizeFactor = 5.0;  // 归一化跨度
float gradient = clamp((maxRadius - dist) / normalizeFactor, 0.0, 1.0);
```

这里`gradient` 近原点 = 1（亮），远原点 = 0（暗），超过 6 个单位后归零。乘以呼吸后做 `pow(10)`：

```hlsl
float rawIntensity = gradient * breath;
float intensity = pow(rawIntensity, 10.0);
```


| dist | gradient | rawIntensity（breath=1） | intensity = pow(x, 10) |
| ---- | -------- | ---------------------- | ---------------------- |
| 0    | 1.0      | 1.0                    | 1.000                  |
| 1    | 1.0      | 1.0                    | 1.000                  |
| 2    | 0.8      | 0.8                    | 0.107                  |
| 3    | 0.6      | 0.6                    | 0.006                  |
| 4    | 0.4      | 0.4                    | 0.0001                 |
| 6    | 0.0      | 0.0                    | 0.000                  |


pow(10) 在这里产生了明显的**门限效应**：gradient 高于 0.8 时 intensity 接近1，低于 0.6 后迅速跌为零。视觉上光晕**高度集中在充电口附近约 2 个单位内**，之外急剧消失——与充电 `pow(2)` 的宽柔和带完全不同。

### 2.2 时间节奏：正弦呼吸替代三角波脉冲

充电特效用 `frac + abs` 构造三角波脉冲，边缘锐利，周期约 1 秒。放电则直接使用 Unity 内置 _SinTime 取绝对值实现：

```hlsl
float breath = clamp(abs(_SinTime.w), 0.0, 1.0);
```

*SinTime.w 本质是* Time.y * π/2 的正弦值，频率约为 0.25Hz（4秒走完一个完整正弦周期）。abs 完成全波整流，把负半周翻转到正半周，最终周期缩短为 2秒（变化过程为 0→1→0→1→0）。和充电的 1 秒三角波相比，放电的呼吸变化更慢、过渡更圆润。

### 2.3 上颜色：蓝色

放电颜色根据设计需要，一般是选用蓝色（比如 (0.29, 0.48, 0.75)）色彩切换通过 `_ISDISCHARGE_ON` Keyword 在同一个 Function 中完成分支选择。

## 三、对比


|         | 充电                      | 放电                     |
| ------- | ----------------------- | ---------------------- |
| 空间模式    | 环形扫描波：frac + smoothstep | 距离梯度：maxRadius - dist  |
| 时间节奏    | 三角波脉冲                   | 正弦呼吸                   |
| 衰减幂次    | pow(2) — 宽柔和带           | pow(10) — 锐利聚焦         |
| 颜色      | 青绿                      | 蓝紫                     |
| Keyword | `_ISDISCHARGE_ON` = off | `_ISDISCHARGE_ON` = on |
| 视觉隐喻    | 能量从充电口**涌入**车体          | 充电口处于**活跃供电**状态        |

## 结语

当前这种放电特效比较简单，所以能写的东西较少。然而，可以总结的是，任何需要在同一材质上切换视觉模式的场景（雨雪、清洗、变色），都可以采用这种**Keyword 分支**方案——共享输入输出，内部路径按模式分叉，编译期剔除未选中的分支，每种模式只承担自己的计算量。
